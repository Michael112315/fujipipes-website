# Fujipipes Website Starter

A responsive Next.js + TypeScript website based on the supplied Fujipipes reference designs.

## Run in VS Code

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- /
- /products
- /solutions
- /projects
- /about
- /contact
- /request-a-quote
- /dealer-locator

## Images

The site uses temporary remote presentation images and placeholders so it works immediately. Replace the image URLs in `components/siteData.ts` and the page files when the final Fujipipes photography is ready.

## Important

Forms are presentation-only in this starter. Connect them to your preferred email/API/backend before production.
